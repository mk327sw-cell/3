# サイト概要

このサイトは、シンプルな静的ページとして情報をわかりやすく伝えることを目的としたミニマル構成のWebサイトです。
閲覧者が迷わず内容を確認できるよう、軽量・直感的な表示をコンセプトにしています。

## 起動方法

1. プロジェクト内の `index.html` を確認します。
2. `index.html` をブラウザで直接開きます（ダブルクリック、またはブラウザにドラッグ＆ドロップ）。
